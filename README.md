# Phoenix Envelopes

A monthly envelope tracker. Log each spend against its envelope, see what is
left, sweep the leftovers into savings at the end of the month.

## Where things live

- **Source of truth:** `~/Desktop/Finance/Phoenix Budget/spending-tracker.html`
- **Numbers behind it:** `~/Desktop/Finance/Phoenix Budget/Phoenix Budget 2026.xlsx`
- `index.html` is **generated** by `make_index.py`. Do not edit it by hand.
  Edit the tracker, then run `Publish.command`, which rebuilds and pushes.
- The icons are generated by `make_icon.py`. Run it if you want to change the
  picture, then `Publish.command`.

## Publishing

Double-click **Publish.command**. The first run creates a public GitHub repo and
turns on Pages. Every run after that pushes an update.

Live at: https://renarsm88.github.io/phoenix-envelopes/

## Putting it on her screen

The page ships an icon set and a web manifest, so it installs like a real app
with the desert sunset picture, not a browser logo.

- **iPhone:** Safari, Share, Add to Home Screen. Opens fullscreen, no address bar.
- **Android:** Chrome, menu, Install app.
- **Mac or Windows:** Chrome or Edge, the install icon in the address bar, or
  menu, Cast Save and Share, Install page as app. It lands in the Dock or Start
  menu with the icon.

## The one thing to understand about the data

On GitHub Pages there is no server and no database. Entries are saved in the
browser's own storage on whichever device she uses.

- Works offline. Needs nobody's computer running.
- Private: nothing is transmitted anywhere.
- **Per-device.** Same phone every time, and do not clear website data for the
  site. Installing it to the home screen makes accidental clearing much less
  likely.
- You will not see her entries. If you need shared data, use the claude.ai
  version instead, which has a real database:
  https://claude.ai/artifact/SVN2QcSDbbYMDf5EqdFnRs

## The envelopes

Eight spending envelopes plus payday transfers, from the workbook. She is paid
hourly, so each month is worth its working days times $132.91 after tax; the
envelopes and the savings transfer stay fixed and the difference lands in the
last bucket.

The furniture envelope runs in **October and November 2026 only**. From December
it disappears and the transfers become Roth $625 / emergency $400 / index fund.
That switch is automatic, set by `FURN_MONTHS` in the tracker.
